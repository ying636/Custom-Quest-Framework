## 修正与限制

- 编译中发现原版 `IntRange` 没有 `Includes`，已改为显式范围比较；测试代码中 `Map.Biomes` 为枚举类型，使用枚举方法访问。
- 跨帧检查发现原版单格门在绘制时根据邻墙自动改变朝向，造成旧预览被误判失效。地图指纹忽略单格门的这种视觉朝向，其位置、数量、耐久和其他建筑朝向继续受检查。修改物品数量仍会在任何生态写入前拒绝旧预览。
- 简体中文首次截图显示英文回退。原版当前目录为 `ChineseSimplified`，旧的带中文括号目录不会被该语言项反向匹配。仅将本功能两份中文资源移到 `1.7/Languages/ChineseSimplified/`，保留其他模块的既有资源；增加当前语言 Key 检查后重新运行并目视确认中文正常。
- 额外 GenStep、第三方任意回调、地图气候、河流流向和原版山体海拔图不在生态资源生成范围。自定义植物列表只控制本次铺设，后续自然生长依基础生态进行。运行期异常记录并停止，不自动回滚已生成内容。
- 本轮针对 1.7，不做旧存档迁移，未验证或部署 1.6。使用方式及保护边界见 [区域布局用法](region-layout-usage.md)。
