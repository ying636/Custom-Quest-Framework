新增第七类布局 `CQF_Layout_Ecology`。先按原版或已加载 Mod 的 BiomeDef 资源及可选自定义配置生成整图生态规划，再在规划后的地形中寻找满足规则的兴趣点，按现有 tag、权重、数量和间距抽取地图部件。自定义项包括地形分布、植物及其权重、植被密度、山石、水域比例与斑块尺度。提供保留当前生态、仅布置兴趣点的模式。

生态规划不修改地图。执行前完成保护、占用、部件、道路和目标标识校验；预览后地图改变则要求重新预览。生态阶段与兴趣点阶段共用保护范围，保留主城、入口以及与保护区相交的整栋建筑。已有人工对象也保留，不通过先清空整张地图再恢复对象实现保护。

兴趣点支持任意适合地块、岸边、山脚、林中空地及开阔地条件，检查完整部件占地、距环境特征距离及入口可达性。沿用区域相对距离、允许方向和部件生成上限。结果登记为带输出 tag 与角色 tag 的区域，供后续脚本引用。

生态身份保存在地图组件，避免修改共享 BiomeDef 或世界地块。原版缺少普通地图的独立生态设置接口时，只对启用此功能的地图增加必要读取适配。任意第三方整图生成脚本不在保护区内直接执行；已加载生态的额外生成行为需要另外适配，不能声称无条件兼容。
