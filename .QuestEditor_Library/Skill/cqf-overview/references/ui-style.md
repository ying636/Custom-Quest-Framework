# CQF 统一 UI 风格

用户确认的范围是全部 CQF 自有编辑器、辅助窗口、游戏对话和任务书窗口。原版嵌入控件保留原有行为，不修改原版全局 GUI 样式。

## 样式入口

实际源码位于 `D:/Game/Steam/steamapps/common/RimWorld/Mods/CQF/.QuestEditor_Library`。

- `QuestEditor_Library/UI/CQFUIStyle.cs`：框架中的共享配色、按钮、图标及边框绘制。框架不能依赖编辑器程序集。
- `QuestEditor_Library/UI/CQFUIScope.cs`：绘制前设定字号、对齐与换行，结束时恢复 GUI 状态。
- `CQF.Editor/CQFEditorPalette.cs`：编辑器配色入口，应与共享配色保持一致。
- `CQF.Editor/AI/CQFAIIconButton.cs`：编辑器中的图标、文字按钮与 Tooltip 入口。

先检查这些文件当前实现再调用；不要另建 Utility 类或在窗口内维护一套不同颜色。

## 外观

- 使用灰蓝色，禁止恢复此前高饱和蓝色。面板、卡片、按钮、悬停和边框从共享配色读取。
- 文字按钮采用底色、DrawBox 边框和文字，正文使用 Small，标题按需使用 Medium，Tiny 仅用于次要信息。
- 正文、标题和次要文字使用共享的 TextColor、Accent、Muted 亮色；不直接使用 Color.gray 绘制空列表或说明文字。
- 所有绘制入口先建立并恢复字体与 GUI 状态，不能依赖上一个窗口留下的字号或颜色。
- 功能图标使用 Mod 已有素材或已核实的原版素材。黄色加减号和折叠箭头通过原版灰度 GUI 材质显示为灰色；只乘灰色 tint 不能消除纹理本身的黄色。
- 对话编辑器可以使用带框图标按钮；其他界面的图片按钮不加方块背景。
- AI 聊天中玩家和 AI 的消息均使用圆角背景；其他按钮不因此改为圆角。
- 错误、警告、完成状态和物品图标可以保留其有意义的颜色。

## 布局与交互

- 常规按钮高约 32，图标按钮约 28–32，行距约 6–8，内容边距约 12；适配实际可用宽度，窄窗口改为上下排列或滚动，不用固定远端横坐标。
- 多项设置采用清晰的字段布局；较长列表使用滚动区域，内容高度覆盖列表和折叠区域。
- 统一风格或修复错位时保留已有布局，不自动调整任务编辑器的字段顺序、同行关系及右侧工具栏；重新布局需用户明确确认。列表添加、移除、粘贴按钮按可用宽度分配，不能与正文或其他按钮共用重叠区域。资源列表须把分组标题计入滚动高度，使用本帧实际绘制高度，不按条目数估算后漏掉分组行；图片选项的提示区域使用实际行高。
- 常规实体生成数据窗口使用固定名称顶栏，下方按生成设置、集群与对话、库存分区；标签与控件共用列，未选择类型时显示选择入口，必要字段错误显示在字段附近。此布局不自动推广到自定义实体定义编辑器。
- 绘制数据字段前用 `CQFUIScope(实际内容宽度)` 传递滚动区或面板的局部宽度；嵌套 scope 恢复上层尺寸。标签和输入框共用字段布局，不使用 350 宽标签配合独立的文字测量定位输入框。
- 无底色的字段选择按钮左对齐，文字按钮居中；列表标题预留右侧图标空间。滚动内容宽度扣除滚动条，不强制最低 620 宽；标签页同时传递实际高度，禁止滚动区超过宿主区域。
- 集群编辑器宽窗口采用设置与实体列表分栏，各自滚动；窄窗口纵向排列。
- 对话树设置使用独立齿轮图标入口，不放进文件菜单。工具栏不提供“属性／收起属性”切换按钮；双击节点、选项或结果打开详情。
- 对话树保留预览和保存时自动校验，不提供单独的检查按钮或检查菜单项。
- 对话节点和选项的删除通过右键菜单；选项保持独立、可共用及拖拽链接。
- 对话结果用拖拽排序替代上下移动按钮。左侧拖拽柄负责排序，文字区域仍可点击编辑；使用原版 ReorderableWidget 的插入提示，改变实际结果优先顺序，刷新连线并记录撤销。
- Tooltip 只注册一次。若按钮绘制函数已处理 Tooltip，调用方不得重复注册同一按钮。额外说明应合并到同一个提示，不增加常驻说明。
- 点击信号字段标签直接打开可搜索的信号本选择窗口，点击列表项即选用；保留手动输入。交互输出信号采用单行选择入口，手动输入放在选择窗口中，不常驻应用、自动信号摘要、关联与刷新操作；交互编辑器不提供检查入口。
- AI 按钮只出现在对话编辑器和任务编辑器，不因统一样式增加其他入口。

## 验证

改共享样式后编译框架与编辑器，检查编辑器关闭时框架仍能独立加载。对排序、共享引用、撤销以及尺寸适配运行相应现有检查。未实际在游戏中查看时，不声称已通过视觉验收。
